---

description: Generate a comprehensive Product Requirements Document from a feature idea.
argument-hint: <feature description>
------------------------------------

Create a professional PRD for: $ARGUMENTS

Requirements:

* Follow modern product management standards.
* Ask clarifying questions only if critical information is missing.
* Output in Markdown.

Sections:

1. Executive Summary
2. Problem Statement
3. Goals
4. Non-Goals
5. Target Users
6. User Personas
7. User Stories
8. Functional Requirements
9. Non-Functional Requirements
10. Success Metrics
11. Edge Cases
12. Acceptance Criteria
13. Risks & Assumptions
14. Future Enhancements

The PRD should be detailed enough for engineering to create a specification document without additional product clarification.
